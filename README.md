# Dad Joke Showdown

A single, deadpan dad joke for the make.fun "Dad Joke Showdown" bounty: one clean pun, delivered straight-faced, with a groan-worthy punchline. The program reads the joke from `entry.txt` and writes it unchanged to the output directory as `entry.txt`.

## The joke

> I told my wife she was drawing her eyebrows too high. She looked surprised.

## How to run

```sh
npm start
```

This writes the joke to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`).
